 🎮 Projetos e Jogos Web

Este repositório reúne jogos e projetos desenvolvidos como demonstração da minha criatividade, lógica de programação e habilidades em desenvolvimento web.

Os projetos utilizam HTML (index), CSS e JavaScript (JS), explorando conceitos de estruturação de páginas, estilização, interatividade, lógica de programação e experiência do usuário.

Além de apresentar projetos práticos, este portfólio demonstra minha capacidade de aprender novas tecnologias, transformar ideias em aplicações funcionais e desenvolver soluções utilizando tecnologias web
